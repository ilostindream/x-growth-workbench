工作原理数据从哪来

数据来自页面自己加载的时间线响应（在页面最早期截获，按 JSON 结构解析，不依赖界面 class 名），零额外网络请求； 补全/同步则打开真实页面复用 X 自己的请求——不伪造任何接口参数，不怕接口改版。 统计按「推文 ID + 本地日期」去重，刷新、重启浏览器不丢。

🔐
权限说明

storage：保存统计数据与设置（全在本机）。
x.com / twitter.com：注入统计脚本。
api.deepseek.com 等域名：仅当你配置了对应 AI 接口时才会发出请求。
pbs.twimg.com / video.twimg.com：媒体下载时拉取文件用（twimg 官方 CDN）。

🛠
故障排查

面板不显示 → 检查「显示面板」是否被关闭、X 是否弹过异常验证。
数字偏小 → 点面板某一行做一次全量同步；自动补全只拉第一页。
深度调试 → 打开「调试日志」后到 x.com 控制台看 [XAM] 前缀日志。
